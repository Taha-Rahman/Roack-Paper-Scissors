# Interactive Rock, Paper, Scissors Game

A clean, modern, and fully responsive Rock, Paper, Scissors game built using vanilla HTML5, CSS3, and JavaScript. 

---

## 🚀 Features

* **Smart Computer AI:** Random, real-time move generation for the computer opponent.
* **Live Score Tracking:** Instantly updates and displays the player's and computer's scores across multiple rounds.
* **Visual Match Results:** Dynamic UI updates that display the choices made and highlight the winner of each round.
* **Responsive Design:** Optimized for seamless gameplay on smartphones, tablets, and desktop monitors.
* **Score Reset:** A quick-restart function to wipe the scoreboard and start a fresh match instantly.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and layout for the game arena and control buttons.
* **CSS3:** Flexbox/Grid centering, custom UI components, hover transitions, and responsive media queries.
* **JavaScript (ES6):** State tracking (scores), logic validation, randomized choice selection, and dynamic DOM updates.
